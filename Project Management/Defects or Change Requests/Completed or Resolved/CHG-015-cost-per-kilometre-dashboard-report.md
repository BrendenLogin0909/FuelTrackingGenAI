# CHG-015: Cost per kilometre dashboard report

## Summary

Add a dashboard report that shows fuel cost per kilometre so users can measure operating cost more accurately than spend alone.

## Metrics

- Cost per kilometre by period
- Cost per kilometre by vehicle
- Fleet average cost per kilometre

## Visual / interaction

- Primary visual: line chart or table
- Filters: date range, vehicle, driver

## Acceptance criteria

1. Users can view cost per kilometre for the fleet and for individual vehicles.
2. The report supports trend view over time and comparison view by vehicle.
3. Calculations only include records with valid spend and distance data.
4. Filters update all displayed calculations consistently.

## Severity / priority

**High**

## Related

- Dashboard page
- Transactions data
- Odometer data
