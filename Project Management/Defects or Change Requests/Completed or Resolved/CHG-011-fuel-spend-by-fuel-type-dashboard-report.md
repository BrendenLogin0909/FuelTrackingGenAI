# CHG-011: Fuel spend by fuel type dashboard report

## Summary

Add a dashboard report that shows how fuel spend and volume are split across fuel categories.

## Metrics

- Spend by fuel type
- Litres by fuel type
- Share of total spend by fuel type

## Visual / interaction

- Primary visual: stacked bar chart or donut chart
- Filters: date range, fuel type, vehicle

## Acceptance criteria

1. Users can view spend and litres split by fuel type.
2. The report shows each fuel type's share of total spend.
3. Filters update the totals and visual breakdown.
4. Transactions with missing fuel type are either excluded or clearly grouped as unknown.

## Severity / priority

**Medium**

## Related

- Dashboard page
- Transactions data
