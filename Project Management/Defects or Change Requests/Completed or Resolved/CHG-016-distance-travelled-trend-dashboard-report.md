# CHG-016: Distance travelled trend dashboard report

## Summary

Add a dashboard report that shows how much distance vehicles travel over time.

## Metrics

- Total distance by week or month
- Average distance per vehicle
- Period-over-period distance change

## Visual / interaction

- Primary visual: line chart
- Filters: date range, vehicle, driver

## Acceptance criteria

1. Users can view total distance travelled over time.
2. The report supports weekly and monthly aggregation.
3. Distances are calculated from valid odometer progression or stored trip totals.
4. Filters update the trend values consistently.

## Severity / priority

**High**

## Related

- Dashboard page
- Odometer data
- Vehicle data
