# CHG-012: Average efficiency trend dashboard report

## Summary

Add a dashboard report that shows overall fuel efficiency over time so users can monitor fleet performance.

## Metrics

- Average fuel efficiency by period
- Period-over-period efficiency change
- Transaction count contributing to each period

## Visual / interaction

- Primary visual: line chart
- Supporting visual: KPI card
- Filters: date range, vehicle, vehicle type

## Acceptance criteria

1. Users can view average efficiency over time using the system efficiency unit.
2. The report shows efficiency movement compared with the previous period.
3. The report only uses transactions with valid fuel and distance data.
4. Filters update the trend and KPI values consistently.

## Severity / priority

**High**

## Related

- Dashboard page
- Transactions data
- Odometer data
