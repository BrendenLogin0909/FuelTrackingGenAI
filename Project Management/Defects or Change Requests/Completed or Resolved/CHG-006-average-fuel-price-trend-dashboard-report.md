# CHG-006: Average fuel price trend dashboard report

## Summary

Add a dashboard report that shows how average fuel price per litre changes over time.

## Metrics

- Average price per litre by period
- Minimum and maximum observed price
- Period-over-period price change

## Visual / interaction

- Primary visual: line chart
- Filters: date range, region, station, fuel type

## Acceptance criteria

1. Users can view average price per litre by time period.
2. The report supports filtering by fuel type and station or region.
3. The report shows price movement versus the previous comparable period.
4. Price calculations use valid transaction values only.

## Severity / priority

**High**

## Related

- Dashboard page
- Transactions data
