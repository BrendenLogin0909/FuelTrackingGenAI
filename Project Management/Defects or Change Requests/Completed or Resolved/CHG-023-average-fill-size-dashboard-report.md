# CHG-023: Average fill size dashboard report

## Summary

Add a dashboard report that shows the average litres purchased per transaction.

## Metrics

- Average litres per fill
- Median litres per fill
- Fill count

## Visual / interaction

- Primary visual: KPI card with supporting bar chart
- Filters: date range, vehicle, station

## Acceptance criteria

1. Users can view average fill size for the selected period.
2. The report shows how many transactions contributed to the result.
3. Filters update the averages consistently.
4. Invalid or zero-litre records are excluded from the average.

## Severity / priority

**Medium**

## Related

- Dashboard page
- Transactions data
