# CHG-045: What changed this month dashboard panel

## Summary

Add a dashboard panel that explains the largest month-over-month movements in key fuel metrics.

## Metrics

- Change in spend
- Change in litres
- Change in average price
- Change in efficiency
- Change in exception count

## Visual / interaction

- Primary visual: narrative summary panel with deltas
- Filters: current month versus previous month, fleet

## Acceptance criteria

1. Users can see a concise explanation of the largest movements from the previous month.
2. The panel highlights both positive and negative movement.
3. The panel uses the same calculations as the underlying detail reports.
4. The feature is designed for rapid scanning rather than deep analysis.

## Severity / priority

**Medium**
