# CHG-025: Day-of-week fueling pattern dashboard report

## Summary

Add a dashboard report that shows fueling activity patterns across days of the week.

## Metrics

- Transaction count by weekday
- Spend by weekday
- Average litres by weekday

## Visual / interaction

- Primary visual: heatmap or bar chart
- Filters: date range, driver, vehicle

## Acceptance criteria

1. Users can view fueling activity grouped by day of week.
2. The report supports transaction count and spend analysis.
3. Day assignment uses the stored local transaction date.
4. Filters update the displayed weekday patterns consistently.

## Severity / priority

**Low**

## Related

- Dashboard page
- Transactions data
