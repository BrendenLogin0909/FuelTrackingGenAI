# CHG-042: Cheapest vs most used stations dashboard report

## Summary

Add a dashboard report that compares fueling behavior against station price competitiveness.

## Metrics

- Spend share by station
- Average price per litre by station
- Usage rank versus price rank

## Visual / interaction

- Primary visual: scatter plot or comparison table
- Filters: date range, driver, vehicle, region

## Acceptance criteria

1. Users can compare which stations are used most often against which stations are cheapest.
2. The report highlights cases where highly used stations are materially above the cheapest available benchmark.
3. The report supports driver-, vehicle-, and region-level filtering.
4. The comparison method is clearly defined in the implementation.

## Severity / priority

**Medium**
