# CHG-043: Carbon emissions estimate dashboard report

## Summary

Add a dashboard report that estimates carbon emissions from recorded fuel consumption.

## Metrics

- Estimated CO2 emissions by period
- Emissions by vehicle
- Emissions intensity per kilometre

## Visual / interaction

- Primary visual: KPI card with line chart
- Filters: date range, vehicle, fuel type

## Acceptance criteria

1. Users can view estimated emissions for the selected period based on fuel consumption.
2. The report documents the conversion factors used by fuel type.
3. Users can compare emissions by vehicle where sufficient data exists.
4. The report clearly states that values are estimates.

## Severity / priority

**Low**

## Related

- Dashboard page
- Transactions data
