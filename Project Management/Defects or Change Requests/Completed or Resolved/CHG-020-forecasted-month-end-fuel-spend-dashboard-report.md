# CHG-020: Forecasted month-end fuel spend dashboard report

## Summary

Add a dashboard report that projects likely end-of-month fuel spend based on current transaction activity.

## Metrics

- Current month actual spend
- Forecasted month-end spend
- Variance to budget

## Visual / interaction

- Primary visual: KPI card with trend projection
- Filters: current month, fleet, vehicle group

## Acceptance criteria

1. Users can view current month spend and forecasted end-of-month spend.
2. The report documents the forecasting method used.
3. The report shows variance between forecast and budget when a budget exists.
4. Forecast values refresh when underlying transactions change.

## Severity / priority

**Medium**
