# CHG-005: Fuel volume trend dashboard report

## Summary

Add a dashboard report that shows total litres purchased over time so users can track fleet fuel consumption volume independently from cost.

## Metrics

- Total litres by week or month
- Average litres per transaction
- Period-over-period volume change

## Visual / interaction

- Primary visual: line chart
- Filters: date range, vehicle, station, fuel type

## Acceptance criteria

1. Users can view litres purchased aggregated over time.
2. The report supports at least weekly and monthly grouping.
3. The report shows period-over-period volume movement.
4. Applying filters updates the displayed totals and trend line.

## Severity / priority

**High**

## Related

- Dashboard page
- Transactions data
