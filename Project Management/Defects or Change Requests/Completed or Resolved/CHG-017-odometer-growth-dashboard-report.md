# CHG-017: Odometer growth dashboard report

## Summary

Add a dashboard report that shows odometer progression per vehicle to help validate usage patterns and mileage growth.

## Metrics

- Odometer over time
- Total odometer increase
- Average kilometres per day

## Visual / interaction

- Primary visual: line chart
- Filters: vehicle, date range

## Acceptance criteria

1. Users can view odometer progression for a selected vehicle across time.
2. The report shows total mileage growth for the selected period.
3. The report surfaces average kilometres per day for the selection.
4. Missing or invalid odometer points do not break the chart.

## Severity / priority

**Medium**

## Related

- Dashboard page
- Odometer data
