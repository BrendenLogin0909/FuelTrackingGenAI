# CHG-004: Monthly fuel spend trend dashboard report

## Summary

Add a dashboard report that shows total fuel spend over time so users can identify spending direction and month-over-month changes.

## Metrics

- Total fuel spend by month
- Previous month comparison
- Month-over-month change amount and percentage

## Visual / interaction

- Primary visual: line chart
- Supporting visual: KPI card for current period spend and change vs previous period
- Filters: date range, vehicle, driver, fuel type

## Acceptance criteria

1. Users can view total fuel spend aggregated by month for a selected date range.
2. The report displays the current period spend and the previous comparable period.
3. The report calculates and displays month-over-month variance in both amount and percentage.
4. Filters update the chart and KPI values consistently.

## Severity / priority

**High**

## Related

- Dashboard page
- Transactions data
