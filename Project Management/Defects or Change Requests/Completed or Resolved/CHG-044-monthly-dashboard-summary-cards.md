# CHG-044: Monthly dashboard summary cards

## Summary

Add top-level dashboard summary cards that provide a quick monthly view of key fleet fuel metrics.

## Metrics

- Current month fuel spend
- Total litres purchased
- Average price per litre
- Average efficiency
- Exception count

## Visual / interaction

- Primary visual: KPI cards
- Filters: current month, fleet, vehicle group

## Acceptance criteria

1. Users can view a concise set of monthly summary metrics at the top of the dashboard.
2. Each card uses the same definitions as the corresponding detailed dashboard reports.
3. Summary cards respond to active dashboard filters where appropriate.
4. Empty states are handled clearly when a metric cannot be calculated.

## Severity / priority

**High**
