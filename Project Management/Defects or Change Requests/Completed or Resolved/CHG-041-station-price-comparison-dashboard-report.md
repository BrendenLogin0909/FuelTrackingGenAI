# CHG-041: Station price comparison dashboard report

## Summary

Add a dashboard report that compares average fuel price across stations to show where fuel is cheapest or most expensive.

## Metrics

- Average price per litre by station
- Variance from regional average
- Transaction count by station

## Visual / interaction

- Primary visual: bar chart or table
- Filters: date range, region, fuel type

## Acceptance criteria

1. Users can compare station prices for a selected region and fuel type.
2. The report shows station price versus a regional benchmark.
3. The report includes transaction count or volume context so low-sample stations are interpretable.
4. Filters update price rankings consistently.

## Severity / priority

**High**
