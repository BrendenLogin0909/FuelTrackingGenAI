# CHG-021: Fuel price inflation impact dashboard report

## Summary

Add a dashboard report that estimates how fuel price increases are affecting total operating spend.

## Metrics

- Average price per litre trend
- Added cost versus baseline period
- Percentage change from baseline

## Visual / interaction

- Primary visual: line chart
- Filters: date range, fuel type, region

## Acceptance criteria

1. Users can compare current fuel prices against a selected or default baseline period.
2. The report estimates added spend attributable to price change.
3. The report shows both absolute and percentage movement from baseline.
4. Filters update the baseline comparison consistently.

## Severity / priority

**Medium**
