# CHG-038: Efficiency decline alert dashboard report

## Summary

Add an alert report that identifies vehicles showing sustained fuel efficiency decline.

## Metrics

- Efficiency trend slope
- Percentage decline versus baseline
- Vehicle variance versus fleet average

## Visual / interaction

- Primary visual: alert list with trend sparkline
- Filters: vehicle, date range

## Acceptance criteria

1. Users can view vehicles flagged for declining fuel efficiency based on configurable rules.
2. Each alert shows the relevant trend period and decline magnitude.
3. The report distinguishes between short-term fluctuation and sustained decline.
4. Users can filter and sort the alert list by severity.

## Severity / priority

**High**
