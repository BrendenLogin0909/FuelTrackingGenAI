# CHG-009: Fuel spend by station or brand dashboard report

## Summary

Add a dashboard report that shows where fuel spend is concentrated across stations and brands.

## Metrics

- Total spend by station or brand
- Total litres by station or brand
- Average price per litre by station or brand

## Visual / interaction

- Primary visual: bar chart
- Supporting visual: sortable table
- Filters: date range, station, brand, region

## Acceptance criteria

1. Users can compare spend across stations and brands.
2. The report supports grouping at station level and brand level.
3. The report displays spend, litres, and average price per litre.
4. Filters update both charted and tabular values consistently.

## Severity / priority

**High**

## Related

- Dashboard page
- Transactions data
