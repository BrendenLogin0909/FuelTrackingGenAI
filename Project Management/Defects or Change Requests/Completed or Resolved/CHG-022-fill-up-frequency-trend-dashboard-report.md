# CHG-022: Fill-up frequency trend dashboard report

## Summary

Add a dashboard report that shows how often vehicles are refueled over time.

## Metrics

- Number of fuel transactions by period
- Average fill-ups per vehicle
- Period-over-period transaction change

## Visual / interaction

- Primary visual: line chart
- Filters: date range, vehicle, driver

## Acceptance criteria

1. Users can view fill-up frequency over time.
2. The report can show total fleet frequency and per-vehicle frequency.
3. The report supports weekly and monthly aggregation.
4. Filters update counts and trends consistently.

## Severity / priority

**Medium**

## Related

- Dashboard page
- Transactions data
