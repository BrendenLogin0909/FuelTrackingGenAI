# CHG-026: Seasonal fuel trend dashboard report

## Summary

Add a dashboard report that shows seasonal patterns in spend, fuel volume, and efficiency.

## Metrics

- Spend by season
- Litres by season
- Average efficiency by season

## Visual / interaction

- Primary visual: line chart
- Filters: multi-year date range, vehicle group

## Acceptance criteria

1. Users can compare seasonal performance across multiple years where data exists.
2. The report supports spend, litres, and efficiency views.
3. Seasonal grouping follows the configured regional calendar.
4. Filters update seasonal comparisons consistently.

## Severity / priority

**Low**

## Related

- Dashboard page
- Transactions data
