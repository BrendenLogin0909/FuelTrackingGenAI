# CHG-008: Fuel spend by driver dashboard report

## Summary

Add a dashboard report that compares fuel spend by driver to identify behavioral or assignment-based cost differences.

## Metrics

- Total spend per driver
- Average spend per fill
- Transaction count per driver

## Visual / interaction

- Primary visual: bar chart
- Filters: date range, driver, vehicle

## Acceptance criteria

1. Users can compare spend across drivers for a selected period.
2. The report shows total spend and average spend per fill for each driver.
3. The report supports filtering by driver and linked vehicle.
4. Drivers without transactions in the selected period are excluded or clearly shown as zero.

## Severity / priority

**Medium**

## Related

- Dashboard page
- Transactions data
- Driver data
