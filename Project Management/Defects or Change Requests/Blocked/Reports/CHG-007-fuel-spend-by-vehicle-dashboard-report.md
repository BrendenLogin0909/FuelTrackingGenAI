# CHG-007: Fuel spend by vehicle dashboard report

## Summary

Add a dashboard report that compares total fuel spend across vehicles to identify the highest-cost vehicles.

## Metrics

- Total spend per vehicle
- Share of total fleet spend
- Average spend per transaction

## Visual / interaction

- Primary visual: bar chart
- Optional supporting visual: sortable table
- Filters: date range, vehicle group, fuel type

## Acceptance criteria

1. Users can compare total spend across vehicles.
2. Vehicles can be ranked highest to lowest by spend.
3. The report shows each vehicle's share of total spend.
4. Filters update chart ordering and values consistently.

## Severity / priority

**High**

## Related

- Dashboard page
- Transactions data
- Vehicle data
