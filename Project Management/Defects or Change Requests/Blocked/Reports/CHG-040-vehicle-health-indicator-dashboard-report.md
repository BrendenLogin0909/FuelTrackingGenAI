# CHG-040: Vehicle health indicator dashboard report

## Summary

Add a dashboard report that uses fuel behavior signals to indicate vehicles that may need attention or maintenance review.

## Metrics

- Efficiency decline score
- Rising cost per kilometre
- Unusual usage pattern indicators

## Visual / interaction

- Primary visual: status panel or scored table
- Filters: vehicle, date range

## Acceptance criteria

1. Users can view vehicles with elevated health-risk indicators based on fuel data trends.
2. The report documents the contributing signals used in the indicator.
3. Each vehicle displays the key reasons it is flagged.
4. The feature is presented as an indicator, not a definitive maintenance diagnosis.

## Severity / priority

**Medium**
