# CHG-018: Vehicle usage distribution dashboard report

## Summary

Add a dashboard report that compares distance travelled across vehicles to identify overused and underused vehicles.

## Metrics

- Total distance per vehicle
- Average distance per week
- Share of total fleet distance

## Visual / interaction

- Primary visual: bar chart
- Filters: date range, vehicle class

## Acceptance criteria

1. Users can compare usage volume across vehicles.
2. The report can rank vehicles from highest to lowest distance travelled.
3. The report shows each vehicle's share of total fleet usage.
4. Filters update chart values consistently.

## Severity / priority

**Medium**

## Related

- Dashboard page
- Vehicle data
- Odometer data
