# CHG-010: Fuel spend by region dashboard report

## Summary

Add a dashboard report that compares fuel spend across operating regions to identify geographic cost differences.

## Metrics

- Total spend by region
- Average price per litre by region
- Total litres by region

## Visual / interaction

- Primary visual: map or bar chart
- Filters: date range, region, vehicle

## Acceptance criteria

1. Users can compare spend across available regions.
2. The report shows spend, litres, and average price per litre by region.
3. The report supports filtering by vehicle and date range.
4. Region grouping is consistent with stored transaction location data.

## Severity / priority

**Medium**

## Related

- Dashboard page
- Transactions data
