# CHG-014: Best and worst efficiency ranking dashboard report

## Summary

Add a dashboard report that highlights the best and worst performing vehicles by fuel efficiency.

## Metrics

- Top efficiency vehicles
- Bottom efficiency vehicles
- Difference from fleet average

## Visual / interaction

- Primary visual: ranked list or bar chart
- Filters: date range, vehicle class

## Acceptance criteria

1. Users can see top-performing and bottom-performing vehicles for the selected period.
2. Rankings are based on the same efficiency calculation used elsewhere in the dashboard.
3. Each ranked vehicle shows variance from fleet average.
4. Vehicles with insufficient data are excluded or clearly marked.

## Severity / priority

**Medium**
