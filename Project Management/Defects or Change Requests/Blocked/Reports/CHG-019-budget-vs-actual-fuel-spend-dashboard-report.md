# CHG-019: Budget vs actual fuel spend dashboard report

## Summary

Add a dashboard report that compares actual fuel spend against configured budgets.

## Metrics

- Budget amount
- Actual spend
- Variance amount and percentage

## Visual / interaction

- Primary visual: bar chart
- Supporting visual: KPI card
- Filters: date range, fleet, vehicle group

## Acceptance criteria

1. Users can compare actual spend against budget for the selected period.
2. The report displays variance in both amount and percentage.
3. The report clearly indicates over-budget and under-budget states.
4. Filters update budget and actual values consistently.

## Severity / priority

**High**

## Related

- Dashboard page
- Budget configuration
- Transactions data
