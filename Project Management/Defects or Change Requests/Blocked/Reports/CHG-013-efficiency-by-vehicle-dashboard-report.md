# CHG-013: Efficiency by vehicle dashboard report

## Summary

Add a dashboard report that compares average fuel efficiency across vehicles.

## Metrics

- Average efficiency per vehicle
- Distance covered per vehicle
- Fuel volume consumed per vehicle

## Visual / interaction

- Primary visual: bar chart
- Filters: date range, vehicle class, driver

## Acceptance criteria

1. Users can compare average efficiency across vehicles in the selected period.
2. Vehicles can be ranked from most efficient to least efficient.
3. The report includes sufficient context to show how much usage contributed to each score.
4. Filters update the results without changing the underlying efficiency formula.

## Severity / priority

**High**

## Related

- Dashboard page
- Transactions data
- Vehicle data
