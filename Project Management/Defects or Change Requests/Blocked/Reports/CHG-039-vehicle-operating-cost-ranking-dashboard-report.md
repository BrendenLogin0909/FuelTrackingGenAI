# CHG-039: Vehicle operating cost ranking dashboard report

## Summary

Add a dashboard report that ranks vehicles by fuel operating cost.

## Metrics

- Total spend by vehicle
- Cost per kilometre by vehicle
- Average efficiency by vehicle

## Visual / interaction

- Primary visual: sortable table or bar chart
- Filters: date range, vehicle class

## Acceptance criteria

1. Users can rank vehicles by total fuel cost and by cost per kilometre.
2. The report shows supporting context including efficiency.
3. The ranking can be filtered by vehicle class and date range.
4. Calculations use the same underlying measures used elsewhere on the dashboard.

## Severity / priority

**Medium**
